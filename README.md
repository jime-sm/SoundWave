SoundWave

SoundWave es una aplicación desarrollada en Java utilizando Programación Orientada a Objetos (POO). El proyecto simula una plataforma básica de música en la que se pueden administrar usuarios, artistas, álbumes, playlists y canciones.
La aplicación funciona desde la consola y permite al usuario consultar información y seleccionar canciones de un catálogo musical.

Funciones de la aplicación
Usuarios
Permite mostrar la información de los usuarios registrados en la aplicación.

Artistas
Contiene información de diferentes artistas, incluyendo sus datos y género musical.

Álbumes
Permite almacenar y mostrar información de los álbumes, como su nombre, año de lanzamiento y cantidad de canciones.

Reproductor
Controla el estado de reproducción de una canción. Permite manejar información como:

Canción que se está reproduciendo.
Estado de reproducción.
Volumen.
Playlists

Permite organizar las canciones en diferentes listas de reproducción.
Catálogo de canciones
La aplicación cuenta con un catálogo de 30 canciones, cada una asociada a su respectivo artista. Las canciones se muestran numeradas para facilitar su selección.

Manual de usuario
Para utilizar SoundWave se debe ejecutar el programa desde un entorno de desarrollo como NetBeans.

1. Iniciar la aplicación
Al ejecutar la clase principal SoundWave.java, el programa muestra inicialmente la información disponible en la aplicación:
Usuarios registrados.
Artistas.
Álbumes.
Playlists.

2. Consultar las canciones
Después de mostrar la información general, aparece el catálogo de canciones disponible.
Cada canción tiene un número que permite identificarla fácilmente.
Ejemplo:
1. Blinding Lights - The Weeknd
2. Save Your Tears - The Weeknd
3. Tití Me Preguntó - Bad Bunny
4. As It Was - Harry Styles
...
30. Canción - Artista
3. Seleccionar una canción

El programa solicita al usuario que introduzca el número de la canción:
Escribe el número de la canción:
El usuario escribe el número correspondiente y presiona Enter.
4. Reproducir la canción
Después de seleccionar una canción, el programa muestra la información correspondiente, como el nombre de la canción y el artista.
También se muestra el estado del reproductor y el volumen configurado.

Ejemplo:

Canción seleccionada: Tití Me Preguntó
Artista: Bad Bunny
Estado: Reproduciendo
Volumen: 70%
5. Finalizar

Una vez realizada la selección, el programa muestra la información de la canción elegida y finaliza la interacción según el funcionamiento establecido en la aplicación.
